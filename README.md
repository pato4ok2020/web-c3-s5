# Описание API: сервис доставки еды

## Пользователь (User)

- POST: /user/ - Регистрация пользователя (все)
- GET: /user/profile/ - Просмотр своего профиля (авторизованный пользователь)
- PUT: /user/profile/ - Изменение своего профиля (авторизованный пользователь)
- DELETE: /user/profile/ - Удаление своего аккаунта (авторизованный пользователь)

## Компания (Company)

- GET: /company/ - Просмотр списка компаний (все)
- GET: /company/:id (id - идентификатор компании) - Просмотр конкретной компании (все)

## Блюда (Product)

- GET: /product/ - Просмотр списка блюд (все)
- GET: /product/:id (id - идентификатор блюда) - Просмотр конкретного блюда (все)
- POST: /product/ - Добавление блюда (компания)
- PUT: /product/:id (id - идентификатор блюда) - Изменение своего блюда (компания)
- DELETE: /product/:id (id - идентификатор блюда) - Удаление своего блюда (компания)

## Корзина (Basket)

- GET: /basket/ - Просмотр своей корзины (клиент)
- POST: /basket/ - Добавление блюда в корзину (клиент)
- PUT: /basket/:id (id - идентификатор позиции корзины) - Изменение количества блюда в корзине (клиент)
- DELETE: /basket/:id (id - идентификатор позиции корзины) - Удаление блюда из корзины (клиент)
- DELETE: /basket/ - Очистка корзины (клиент)

## Заказы (Order)

- POST: /order/ - Оформление заказа из корзины (клиент)
- GET: /order/ - Просмотр списка своих заказов (клиент, компания)
- GET: /order/:id (id - идентификатор заказа) - Просмотр конкретного заказа (клиент, компания)
- PUT: /order/:id/status (id - идентификатор заказа) - Изменение статуса заказа (компания)
- PUT: /order/:id/cancel (id - идентификатор заказа) - Отмена заказа (клиент, компания)

## Отзывы (Feedback)

- GET: /feedback/ - Просмотр списка отзывов о компании (все)
- POST: /feedback/ - Добавление отзыва компании (клиент)
- PUT: /feedback/:id (id - идентификатор отзыва) - Изменение своего отзыва (клиент)
- DELETE: /feedback/:id (id - идентификатор отзыва) - Удаление своего отзыва (клиент)
